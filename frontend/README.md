# Brilliant: interfaz

Interfaz en Flutter del juego de dados Brilliant (un jugador, tablero de 7x7).
La lógica del juego está en el paquete `juego_brilliant` de la raíz del
repositorio, que se incluye como dependencia con `path: ..`.

## Pruebas

```sh
# En esta carpeta (frontend/)
flutter test

# Dominio, en la raíz del repositorio
dart test
```
